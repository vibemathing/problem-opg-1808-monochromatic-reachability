## 显式对象

V={a,b,c,d}。完整弧表：

| 弧 | 颜色 |
|---|---:|
| a→b | 1 |
| b→c | 1 |
| c→a | 3 |
| a→d | 2 |
| d→b | 1 |
| d→c | 2 |

Hamilton 有向环 a→d→b→c→a 经过全部四个顶点，所以 tournament 强连通。

## 更强前提的核对

忽略方向后，全部四个三角形的颜色多重集分别为：
abc: {1,1,3}；abd: {1,1,2}；acd: {2,2,3}；bcd: {1,1,2}。
没有任何无向彩虹三角形，因而也没有彩虹有向三环。

## 统一颜色—方向模块

称非空集合 M 为颜色—方向模块，若对每个 z∉M，z 与 M 中所有顶点间的弧同色且相对于 z 同向。
所要求分块中的每个块都必须是这种模块：将 z 所在块与 M 对照即可。

六个二元集合均不是模块，外部区分顶点如下：

| M | z | 冲突 |
|---|---|---|
| {a,b} | c | c→a，但 b→c。 |
| {a,c} | b | a→b，但 b→c。 |
| {a,d} | c | c→a，但 d→c。 |
| {b,c} | a | a→b，但 c→a。 |
| {b,d} | a | a→b 颜色1，a→d 颜色2。 |
| {c,d} | a | c→a，但 a→d。 |

每个三元集合也不是模块。其唯一外部顶点都有入邻点和出邻点：
a 出向 b,d、入自 c；b 出向 c、入自 a,d；
c 出向 a、入自 b,d；d 出向 b,c、入自 a。

所以任何非平凡合格分块只能全部为单点块。但全单点缩约使用全部三种颜色，仍不合格。
此论证覆盖四顶点的所有集合分块，不只是二块分解。

## 明确展示经典无向 Gallai 分块为何不能直接使用

忘掉方向后，{a,c}、{b}、{d} 是合法的 Gallai 分块：
{a,c} 与 {b} 之间全为颜色1，{a,c} 与 {d} 之间全为颜色2，b 与 d 之间为颜色1。
然而 {a,c} 与 b 之间是 a→b→c；与 d 之间是 a→d→c。统一方向均失败。

因此该例隔离出两个不同问题：
三顶点反例允许无向彩虹三角形；本例连无向彩虹三角形也排除了，统一方向仍无保证。

## 最小性与原题

强连通的三顶点 tournament 只能是有向三环。没有彩虹有向三环时，它至多用两种颜色，
所以全单点分块合格。四顶点因此是强连通类中的最小分解障碍。
若只加强为无向 Gallai 条件，则任意 n≤3 的对象至多用两种颜色，仍由全单点分块处理。

a→b 和 a→b→c 都为颜色1，a→d 为颜色2。
故 a 单色可达到全部其他顶点。本例仍不是原问题的反例。
