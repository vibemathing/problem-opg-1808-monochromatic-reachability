## Frozen scope and conventions

The admitted target asks whether every finite three-arc-coloured tournament
without a rainbow directed triangle has a nontrivial vertex partition whose
cross-arcs are uniform in both colour and direction for each pair of parts,
and whose quotient uses at most two colours.

Test the most permissive useful inductive version: n >= 2 and 2 <= k <= n
nonempty parts. Singletons and the discrete partition are allowed. Colours
form the set {R,B,G}; surjectivity is not required, but the witness uses all
three. Empty and one-vertex cases are not used to manufacture an obstruction.
If "nontrivial" additionally excludes the discrete partition, the same witness
still has no permitted partition; the minimality assertion below is only for
the explicitly stated permissive convention.

A path is directed and has one common arc colour. Its colour may depend on
the target vertex, exactly as in the ProblemContract. Only finite-digraph
basics and finite combinatorics are used. The target has no dependency nodes.

## Exact witness

V = {a,b,c}. The complete arc list, with no other arcs, is:

| Tail | Head | Colour |
| --- | --- | --- |
| a | b | R |
| b | c | B |
| a | c | G |

The orientation is the total order a < b < c, hence is a tournament and has
no directed cycle. In particular it has no rainbow directed triangle. Its
underlying undirected triangle is rainbow; the directed hypothesis allows it.

## Exhaustive partition certificate

There are exactly four partitions into at least two nonempty parts:

| Partition | Decisive failure |
| --- | --- |
| {a} / {b,c} | a->b is R but a->c is G: cross-arcs have different colours. |
| {b} / {a,c} | a->b and b->c point in opposite directions relative to the two parts. |
| {c} / {a,b} | a->c is G but b->c is B: cross-arcs have different colours. |
| {a} / {b} / {c} | The quotient is the witness itself and uses R, B and G. |

Completeness of the table is elementary: a two-part partition of a three-element
set has a unique singleton, yielding the first three rows; a three-part
partition must be discrete. A one-part partition is excluded by definition.
Thus every allowed partition violates a target condition.

## Adversarial checks and source gap

Allowing singleton parts does not rescue the partition (last row). Requiring
all three colours to occur does not exclude this witness. Removing direction
uniformity alone does not rescue it: in every two-part partition the two
cross-arcs also have different colours. Removing the two-colour quotient bound
does rescue the discrete partition, so that bound must not be omitted.

Classical Gallai partitions assume that every underlying triangle is
non-rainbow, including transitive triples. They also do not impose direction
uniformity. The source comparison is in
`research/artifacts/source-notes/opg1808-a01-c01-sources-20260906.md`.
That theorem is not invoked as a lemma of this certificate.
